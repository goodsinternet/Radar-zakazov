# Как выложить «Радар заказов» на Vercel — инструкция для не-программиста

Займёт ~15 минут. Понадобятся: аккаунты GitHub и Vercel (у вас есть) и
бесплатный аккаунт Upstash (создадим по ходу). Всё по шагам, копировать
можно кнопками.

> Что получится: сайт с вашим радаром, доступный из браузера с любого
> устройства, обновление заказов при каждом открытии страницы.

---

## Шаг 1. Хранилище ключей (Upstash) — 4 минуты

У Vercel нет «жёсткого диска», поэтому ключ Telegram-сессии будем хранить
в бесплатном облачном хранилище Upstash.

1. Откройте **upstash.com** → кнопка **Sign Up** → **Continue with GitHub**
   (разрешите доступ).
2. Слева выберите **Redis** → кнопка **Create database**.
3. Заполните:
   - **Name**: `radar`
   - **Primary Region**: любая, лучше близкая — `eu-central-1 (EU)`
   - Остальное не трогайте.
4. Нажмите **Create**.
5. Откроется страница базы. Прокрутите до секции **REST API** и нажмите
   **Copy .env values** (или скопируйте по одному две строки):
   - `UPSTASH_REDIS_REST_URL=...`
   - `UPSTASH_REDIS_REST_TOKEN=...`

   **Сохраните их в блокнот** — понадобятся на шаге 3.

## Шаг 2. Код на GitHub — 5 минут

1. Распакуйте архив `radar-vercel.zip` в папку, например `Радар`.
2. Откройте **github.com** → войдите → в правом верхнем углу **+** →
   **New repository**.
3. Название: `radar`. Выберите **Private** (важно — репозиторий личный).
   Нажмите **Create repository**.
4. На открывшейся странице найдите ссылку **uploading an existing file**
   и нажмите её.
5. Откройте папку `Радар`, выделите **всё её содержимое** (Ctrl+A) и
   перетащите в окно GitHub. Дождитесь, пока все файлы загрузятся
   (появятся в списке).
6. Нажмите зелёную кнопку **Commit changes**.

## Шаг 3. Деплой на Vercel — 4 минуты

1. Откройте **vercel.com** → войдите через GitHub.
2. Нажмите **Add New... → Project**.
3. В списке найдите репозиторий `radar` → **Import**.
4. На странице настроек раскройте раздел **Environment Variables** и
   добавьте три переменные (кнопка Add после каждой):

   | Name | Value |
   |---|---|
   | `UPSTASH_REDIS_REST_URL` | строка из блокнота (шаг 1) |
   | `UPSTASH_REDIS_REST_TOKEN` | строка из блокнота (шаг 1) |
   | `APP_PASSCODE` | **придуманный пароль для входа на сайт** |

   Всё остальное (Framework, Build Command) Vercel заполнит сам —
   не трогайте.
5. Нажмите **Deploy** и подождите 2–3 минуты (сборка идёт автоматически).
6. Готово — Vercel покажет адрес вида `radar-xxxx.vercel.app`.
   Нажмите **Visit**.

## Шаг 4. Первая настройка на новом месте — 3 минуты

1. Откроется страница входа — введите `APP_PASSCODE`, который придумали.
2. Нажмите **Подключить Telegram** и повторите вход: api_id и api_hash —
   **те же самые** с my.telegram.org (если потеряли — там же посмотреть:
   my.telegram.org → API development tools), затем телефон и код.
   Аккаунт один и тот же — просто «рукопожатие» с нового сервера.
3. Добавьте каналы (Воркзавр, Web Freelance и другие — есть в списке
   подсказок) и вернитесь к радару.

## Если адрес .vercel.app не открывается

Роскомнадзор иногда блокирует отдельные поддомены — зависит от провайдера.
Варианты:

- проверить с телефона через мобильный интернет (через Wi-Fi может
  блокироваться, а через LTE — нет);
- подключить свой домен (~300 ₽/год, Reg.ru/Any.name): Vercel →
  Project → Settings → Domains → Add; домен направляется на Vercel
  автоматически;
- если ничего не помогает — переезд на VPS (скажите, подготовлю).

## Частые вопросы

**Обновится ли сайт сам, если я поменяю код?**
Да: обновите файлы в репозитории GitHub (upload файлов → Commit) — Vercel
пересоберёт сайт автоматически через пару минут.

**Забыл пароль от сайта.**
Vercel → Project → Settings → Environment Variables → поменяйте
`APP_PASSCODE` → Redeploy. Войдите с новым паролем.

**Это безопасно?**
Пароль от Telegram никуда не вводится и не хранится. Сессия хранится в
вашем личном Upstash-хранилище, доступном только по вашему токену.
Сайт закрыт паролем. Отключение — кнопка «Отключиться» на странице
Telegram отзывает сессию.

**Сколько это стоит?**
Vercel Hobby, Upstash Free и GitHub — бесплатно для личных проектов.
Лимиты бесплатного тарифа (10 000 обращений к хранилищу в сутки) для
одного человека — с большим запасом.

**А уведомления в Telegram, как обещали?**
Это следующий шаг: бот будет писать вам, когда в каналах появится заказ
под ваш профиль. Скажете — добавлю, а «будильник» уже готов
(cron-задание в vercel.json).
